# Garage Gains

A web application for home gym workout management and generation.

## Features

- **Equipment (Kit)** — Browse home gym equipment organized by category
- **Exercises** — Filterable database of exercises by muscle group
- **Generate** — Build workout routines based on type, focus, duration, and intensity with a built-in workout timer
- **Timer** — Standalone countdown timer with presets and custom input

## Usage

Open `index.html` directly in a browser. No build step, package manager, or server required.

## Tech Stack

Vanilla HTML, CSS, and JavaScript — zero dependencies.
